# 用户画像

## 核心用户

### 毕业求职困难群体（社招）

```
基本信息：
- 年龄：22-25 岁
- 学历：本科/硕士
- 状态：已毕业 0-2 年，求职不顺利
- 求职类型：社招（非校招）
```

### 典型画像

**画像 A：转行失败的小张**
- 普通本科毕业，专业不对口
- 投了很多岗位但面试机会少
- 不确定自己适合什么，看到 JD 觉得"好像都能投又好像都不匹配"
- 痛点：**方向迷茫**——不知道什么岗位适合自己

**画像 B：经验不足的小李**
- 211 本科，但大学期间没有实习
- 毕业后做了一段时间不相关的工作，想转行
- 看到 JD 上"3年经验"就放弃，不知道自己的经历怎么包装
- 痛点：**能力差距**——不知道自己差什么、怎么补

**画像 C：信息闭塞的小王**
- 二本/三本毕业，在小城市
- 求职信息来源有限，不知道大厂/好岗位的真实要求
- 看到高大上的 JD 描述就自我否定
- 痛点：**信息不对称**——不知道 JD 背后的真实含义

## 用户场景

### 场景 1：JD 解读
> 小李在 BOSS 直聘看到一个"产品经理"岗位，JD 写着"负责产品全生命周期管理"。小李不确定这是不是自己能做的，用 JD 真话解读后发现，实际工作主要是需求文档撰写和原型设计，自己大学做过类似项目，可以尝试。

### 场景 2：能力差距分析
> 小王想投一个"前端开发"岗位，但 JD 要求"熟悉 React 和工程化"。解读后发现自己只会 Vue，报告给出了"Vue 转 React 的学习路径 + 预计时间 + 练手项目建议"。

### 场景 3：行动规划
> 小张通过多次解读不同岗位的 JD，发现"运营"类岗位最匹配自己的能力，报告给出了"先做 2 个运营项目 → 优化简历 → 投递策略"的行动清单。

## 为什么不是校招学生？

| 维度 | 校招 | 社招 |
|------|------|------|
| 筛选逻辑 | 学历/实习/项目 | 经验/能力匹配 |
| JD 重要性 | 低（主要看学校和项目） | 高（核心筛选标准） |
| 信息不对称程度 | 中（有学长学姐/就业办） | 高（缺乏信息渠道） |
| JD 解读价值 | 低 | **高** |

**结论**：毕业求职困难群体参加社招，JD 是核心筛选标准，解读 JD 对他们价值最大。
