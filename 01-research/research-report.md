# Phase 1 调研报告 — JD 真话

> 调研日期：2026-04-17
> 调研范围：JD 样本收集 + 竞品分析（跳过访谈提纲）
> 目标：为 MVP 功能需求提供决策依据

---

## 一、调研结论速览

### 1.1 核心发现

| 发现 | 结论 | 对 MVP 的影响 |
|------|------|--------------|
| **市场空白确认** | 没有任何竞品以"真实从业者经验 + AI"做 JD 深度解读 | ✅ 方向成立，全力推进 |
| **JD 样本验证** | 21 条真实 JD 中大量存在"黑话/模糊描述"，AI 解读有明确价值 | ✅ 核心场景验证 |
| **差异化壁垒** | 5 个竞品未覆盖的差异化点已识别 | ✅ 产品壁垒清晰 |
| **竞品红海警示** | 简历优化、面试模拟已是红海，不应进入 | ⚠️ 明确边界 |

### 1.2 关键决策建议

| 决策项 | 建议 | 理由 |
|--------|------|------|
| MVP 核心功能 | JD 智能解读（四维结构化报告） | 市场完全空白，所有竞品均未覆盖 |
| 是否做用户背景输入 | **V0.1 不做**，V0.5 加入 | JD 样本显示 0-2 年用户首要需求是"理解岗位"，不是"对比差距" |
| 是否做简历优化 | **不做** | AI 简历姬已占据头部位置，正面竞争无胜算 |
| 是否做面试模拟 | **不做** | 智语面试/牛客已覆盖，投入产出比低 |
| 经验知识库策略 | 人工采集种子数据 + 关键词匹配 RAG | 数据量小时向量检索无优势，关键词匹配够用 |
| 聚焦岗位类别 | 前端/后端/产品/运营/设计/数据分析 | JD 样本覆盖充分，用户需求最大 |

## 二、JD 样本分析

### 2.1 收集概况

- **总量**：21 条真实 JD
- **来源**：BOSS 直聘（20 条）+ 智联招聘（1 条）
- **覆盖岗位类别**：6 个（前端 4 条、后端 3 条、产品 3 条、运营 4 条、设计 4 条、数据分析 3 条）
- **经验范围**：经验不限 ~ 5-10 年，以 1-3 年为主（匹配目标用户）

### 2.2 JD "黑话/模糊描述"分析

从 21 条 JD 中提取的高频"黑话"模式：

| 黑话类型 | 典型表述 | 出现频次 | 真实含义（推测） |
|----------|---------|---------|----------------|
| 职责夸大 | "负责产品全生命周期管理" | 3 次 | 实际可能是写文档+跟进开发+验收 |
| 能力模糊 | "良好的设计和编码品味" | 2 次 | 写代码规范、能 review |
| 范围宽泛 | "构建业务数据分析体系" | 2 次 | 写 SQL 取数+做报表+出分析 |
| 隐性要求 | "能承受工作压力" | 3 次 | 加班多/节奏快 |
| 经验虚标 | "3-5年经验"（实际要求 1 年技能） | 多处 | 简历筛选门槛，非硬性要求 |
| 流程术语 | "产品包需求规格书""产品退市工作评估" | 2 次 | 文档撰写和流程跟进 |

### 2.3 对 MVP 的启示

1. **解读重点应放在"翻译黑话"上**：JD 样本中大量模糊描述，这是产品最能体现价值的场景
2. **需要区分"JD 写的"和"实际要的"**：如 jd_009 产品经理岗位列了 7 大职责，但实际初级产品经理主要做需求文档和原型
3. **"隐性要求"解读是差异化亮点**：如"能承受压力"= 加班，"有创业精神"= 资源有限
4. **经验要求需要"降维翻译"**：JD 写 3 年经验，但实际需要的技能可能 1 年就能掌握

## 三、竞品分析要点

### 3.1 竞品格局

```
                    JD 解读深度
              低 ───────────────── 高
           ┌─────────────────────────────┐
      高   │  脉脉/看准网    AI 简历姬    │
      │    │  （真实经验）   （JD 匹配）   │
      │    │                             │
  真实    │       【空白区域】            │
  经验    │     "JD 真话" 目标位置        │
  注入    │                             │
  程度    │  通用 AI        超级简历     │
      │    │  （泛化回答）   （JD 对齐）  │
      低   │  知页简历       智语面试     │
           │  智蛙面试       牛客        │
           └─────────────────────────────┘
```

### 3.2 五个差异化机会

| # | 差异化点 | 竞品现状 | JD 真话的机会 |
|---|---------|---------|--------------|
| 1 | **真实从业者经验 + AI 深度解读** | 所有竞品均无此机制 | 通过 RAG 注入结构化经验数据，提供"问 ChatGPT 得不到"的信息 |
| 2 | **JD → 真实工作内容的结构化翻译** | 竞品停留在关键词提取 | 揭示 JD 潜台词，翻译为"日常到底做什么" |
| 3 | **差距分析 + 行动建议闭环** | 无竞品提供 | "理解岗位 → 认识差距 → 采取行动"的完整链路 |
| 4 | **UGC 经验贡献机制** | 牛客有面经 UGC 但非 JD 维度 | 以"岗位 JD"为粒度收集经验，形成数据飞轮 |
| 5 | **聚焦 0-2 年求职困难群体** | 竞品面向全阶段 | 针对性设计"岗位入门指南"式解读 |

### 3.3 MVP 应避免的红海

| 功能 | 红海竞品 | 原因 |
|------|---------|------|
| 简历生成/优化 | AI 简历姬（头部）、超级简历、知页简历 | 已有成熟玩家，正面竞争无胜算 |
| 面试模拟 | 智语面试、牛客、智蛙面试 | 功能同质化严重 |
| 岗位搜索/推荐 | BOSS 直聘、前程无忧、猎聘 | 平台垄断，难以差异化 |
| 通用 AI 对话 | ChatGPT、Kimi、豆包、DeepSeek | 直接竞争无胜算 |

## 四、MVP 功能需求建议（待你决策）

基于调研结论，以下是 MVP 功能需求的建议方案：

### 4.1 P0 — 必须有（核心差异化）

| 功能 | 描述 | 验收标准 |
|------|------|---------|
| **F1: JD 智能解读** | 输入 JD 文本 → AI 生成四维结构化报告（真实工作内容 + 核心能力要求 + 从业者经验洞察 + 行动建议） | 质量评估 ≥ 20/25 |
| **F2: 经验知识库（RAG）** | 5-10 个岗位的种子经验数据，关键词匹配检索注入 Prompt | 经验相关性 > 70% |
| **F3: 岗位类别选择** | 用户可选前端/后端/产品/运营/设计/数据分析，辅助精准匹配 | 匹配准确率 > 80% |

### 4.2 P1 — 应该有（体验增强）

| 功能 | 描述 | 理由 |
|------|------|------|
| **F4: 解读历史** | 保存用户的解读记录，方便回顾对比 | 提升复用率，目标 > 20% |
| **F5: JD 潜台词翻译** | 在报告中单独高亮"JD 写的 vs 实际意思" | 差异化亮点，用户感知最强 |
| **F6: 反馈评分** | 每次解读后可评分（1-5 分）+ 收集改进建议 | 数据驱动迭代 |

### 4.3 P2 — 可以有（时间允许则做）

| 功能 | 描述 | 理由 |
|------|------|------|
| **F7: 用户背景输入** | 输入学历/经验/技能，生成个性化差距分析 | V0.1 非刚需，V0.5 再做 |
| **F8: 多 JD 对比** | 对比 2-3 个岗位的解读结果 | 帮助用户做选择，但增加复杂度 |
| **F9: 分享功能** | 生成解读报告图片，支持分享到微信 | 裂变增长，但 Demo 阶段优先级低 |

### 4.4 明确不做

- ❌ 简历生成/优化
- ❌ 面试模拟
- ❌ 岗位搜索/推荐
- ❌ 通用 AI 对话
- ❌ UGC 经验贡献（V0.1 阶段）

## 五、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 经验知识库数据不足 | 解读质量依赖经验数据质量 | 人工从知乎/脉脉/面经等公开渠道采集高质量种子数据 |
| 通用 AI 快速进化 | ChatGPT 等可能缩小差距 | 持续积累真实从业者经验数据（通用 AI 无法获取的壁垒） |
| 用户不会写 JD | 输入质量影响输出质量 | 提供输入引导（"建议粘贴完整 JD"）+ 容错处理 |
| 小程序性能限制 | 复杂 AI 交互体验差 | 保持功能精简，核心流程"输入 JD → 获取解读"一步到位 |
